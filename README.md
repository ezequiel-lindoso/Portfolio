# Sobre Mim

Este é o meu primeiro projeto: um portfólio desenvolvido utilizando **HTML, CSS e JavaScript**.

Criei este espaço com o objetivo de apresentar meus projetos mais importantes, minhas habilidades e as experiências profissionais que construirei ao longo da minha carreira.

Como estou iniciando minha trajetória na área de tecnologia, o portfólio ainda está em constante desenvolvimento e, por enquanto, possui poucos conteúdos. Pretendo atualizá-lo continuamente à medida que adquirir novos conhecimentos, desenvolver projetos e conquistar novas experiências.

Este projeto representa o início da minha jornada na programação e o meu compromisso com o aprendizado e a evolução constante.
